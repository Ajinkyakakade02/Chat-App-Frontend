# Chat App Frontend 💬

A real‑time chat application built with **React**, **Material UI**, and **Redux**.  
Connects to a Spring Boot backend for authentication, user management, and WebSocket messaging.

## ✨ Features
- Phone number + password login (OTP support on backend)
- Real‑time messaging via STOMP/WebSocket
- Dark/light theme with MUI
- Responsive sidebar with chat list, contacts, starred messages
- Emoji picker, file attachments, and voice/video call icons
